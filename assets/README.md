# Audio assets

`piano-c2.ogg`, `piano-c4.ogg`, and `piano-g4.ogg` are forte samples from
Splendid Grand Piano, a sampled Steinway released to the public domain.
ChordPath picks the nearest compact anchor and pitch-shifts it locally so note
preview works across the exercise range, offline and without a CDN.
